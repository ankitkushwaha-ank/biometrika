Getting Started

Biometrika-Core provides human verification for your web applications through behavioral analysis. This guide will help you integrate it in minutes.

Installation

NPM

npm install @biometrika/core

CDN

<script src="https://cdn.biometrika.io/v1/biometrika.min.js"></script>

Configuration

Initialize Biometrika-Core with your site key:

import { Biometrika } from '@biometrika/core'; const client = new Biometrika({ siteKey: 'YOUR_SITE_KEY', mode: 'invisible', // or 'visible' theme: 'light' // or 'dark' });

Verification

Verify a user interaction:

const result = await client.verify(); if (result.verified) { console.log('User verified:', result.token); // Send token to your backend } else { console.log('Verification failed:', result.reason); }

API Reference

Biometrika Class

Constructor: new Biometrika(options)

Methods:

  • verify() - Initiates verification process
  • reset() - Resets verification state
  • destroy() - Cleans up resources

Examples

Login Form Protection

document.getElementById('loginForm').addEventListener('submit', async (e) => { e.preventDefault(); const result = await client.verify(); if (result.verified) { // Submit form with token submitLogin(result.token); } });
